# Paradise Nursery

Paradise Nursery is an online plant shop built with React and Redux Toolkit. Users can browse plants, add them to a shopping cart, and manage the items in their cart.

## Project Name

**Paradise Nursery**

## Features

- Landing page with the company name, a short introduction, and a "Get Started" button
- Product listing page with plant images, names, descriptions, and prices, grouped by category
- Add to cart, with the button disabled once a plant has been added
- Navigation bar with links to the home, plants, and cart pages
- Cart icon that shows the total number of items in the cart
- Shopping cart page where you can:
  - Increase or decrease the quantity of each plant
  - Delete a plant from the cart
  - See the subtotal for each plant and the total cost of the cart
- "Continue Shopping" and "Checkout" buttons

## Tech Stack

- React (Vite)
- Redux Toolkit
- JavaScript, HTML, CSS

## How to Run

2. Go into the folder: `cd <repo-name>`
3. Install dependencies: `npm install`
4. Start the app: `npm run dev`
